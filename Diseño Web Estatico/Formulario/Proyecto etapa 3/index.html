Pequeña reflexión


1. ¿Por qué utilizaste radio para la modalidad y checkbox para los conocimientos previos?

Porque para la modalidad se elige opción única, mientras que los conocimientos previos pueden ser muchos o ninguno.


2. ¿Para qué se utiliza la etiqueta label?

Para asociar un texto con un elemento del formulario.

3. ¿Qué diferencia existe entre input type="text" e input type="email"?

El input type="email" valida que el valor ingresado sea una dirección de correo electrónico válida y el input type="text" no valida nada en específico.
